# API 参考

xhjob 提供三层 API：底层 PHP 函数（27 个 `xhjob_*`）、PHP 链式 builder（TaskBuilder）、面向对象的 TaskManager。

- [PHP 函数参考](api-functions/) — 全部 27 个 `xhjob_*` 函数 + `Xhjob` 类
- [TaskBuilder API](api-taskbuilder/) — 静态工厂与 40+ 链式方法
- [TaskManager API](api-taskmanager/) — 面向对象的任务管理器
